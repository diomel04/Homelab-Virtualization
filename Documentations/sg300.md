# Homelab Documentation: Cisco SG300-20 Switch Configuration

### Role
The SG300 acts as a Layer 3 switch responsible for:
* **Inter-VLANs** routing between VLANs 10,20,30 and 99.
* **IP Helper** frowards DHCP request from VLANs to the Windows Server DHCP on VLAN 30
* **ACLs** restricts unauthorized traffic between VLANs

### VLAN Design

|VLAN NAME|VLAN ID|NETWORK ADDRESS|SUBNET MASK|PURPOSE|
|-|-|-|-|-|
|Trusted Network 1|10|172.168.8.1|255.255.252.0|Workstation Segment 1|
|Trusted Network 2|20|172.16.20.1|255.255.252.0|Workstation Segment 2|
|Servers|30|172.16.30.1|255.255.255.240| Servers AD,DHCP,DNS & File Server
|Management|99|172.16.99.1|255.255.255.248|Admin Access, Management|

![](/img/vlans.png)


### VLAN Port Assignment

|Port Range|VLAN|MODE|DESCRIPTION|
|----------|----|----|-----------|
|Ge1|Trunk|Tagged VLAN 1,10,20,30,40,99| Uplink to pf Sense ( all VLANs )
|Ge2-3|1 Native|Access|Management for switch|
|ge4-5|99|Access|Managemt port|
|ge6-10|10|Access|Trusted Workstation 1|
|ge11-15|20|Access|Trusted Workstation 2|
|ge16-20|-|-|future expansion|

![](/img/vlan%20tag.png)

**Notes**
1. Ge2-3 was on Native to Manage the SG300 switch via https because the console port is not working.
2. Servers was not on the Vlan Port Assignment because All servers are VM and located at vimbr1 vlan aware.

### DHCP Relay / IP Helper

go to `IP Configuration -> DHCP Snooping/Relay -> Properties`then check the box to enable DHCP relay.

go to `IP Configuration -> DHCP Snooping/Relay -> Interface Settings` then add all the vlans that needed the ip helper to locate the DHCP Server.
